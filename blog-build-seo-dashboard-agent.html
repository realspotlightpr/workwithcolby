Build your own SEO dashboard agent.

Use Codex or Claude to turn scattered search data into an organized audit, dashboard and action queue—without giving an agent permission to spam the web.

By Colby Fifer · Updated August 2026

Most SEO dashboards show charts. A useful SEO command center should also explain what changed, what evidence supports the diagnosis and what action should happen next.

The free prompt pack below gives an AI coding agent durable operating rules for auditing a site, planning the dashboard, protecting secrets and keeping external actions approval-gated.

What the agent should track

  • Search Console clicks, impressions, CTR and position.
  • Technical health, crawl issues and indexation.
  • Query and landing-page movement.
  • Content coverage and internal-link gaps.
  • Legitimate citations, backlinks and mentions.
  • Conversion events and qualified inquiries.
  • A prioritized queue with evidence, impact, effort and owner.

Step 1: place the instructions correctly

For Codex, place AGENTS.md in the repository root and start a new session from the project. Codex reads these project instructions before doing work and applies more specific nested instructions closer to the working directory.

For Claude, include the supplied CLAUDE.md beside the shared instructions and explicitly ask the agent to read both files before acting.

Step 2: audit before building

Have the agent inventory pages, metadata, headings, canonicals, schema, links, sitemap rules, images and mobile risks. The dashboard schema should emerge from evidence the site can actually access—not from attractive placeholder numbers.

Step 3: connect data safely

Use approved authentication for Search Console, analytics and any backlink provider. Keep credentials in environment variables or a secure integration. Never place API keys in a prompt, front-end JavaScript or a committed file.

Step 4: distinguish facts from scores

A click count is source data. A “content opportunity score” is a calculation. Label both clearly, document formulas and show an unavailable state when a source is disconnected.

Step 5: keep the agent on a leash

Researching backlink opportunities is low risk. Creating accounts, submitting profiles and emailing strangers changes external state. The prompt pack requires explicit approval before those actions and rejects automated directory blasts, fake profiles and paid-link networks.

Step 6: measure outcomes

Record deployments, wait for recrawling and compare appropriate periods. SEO is affected by competition, seasonality, algorithm changes and demand. Do not turn correlation into a victory claim.
