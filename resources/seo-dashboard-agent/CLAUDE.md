# Claude SEO Dashboard Agent

Use the complete operating instructions in `AGENTS.md` as the source of truth. If your Claude workflow expects `CLAUDE.md`, keep this file in the repository root beside `AGENTS.md` and follow both.

## First task

Audit this repository and design an SEO command center without deploying anything.

1. Inventory every indexable page and identify its search intent.
2. Audit titles, descriptions, headings, canonicals, structured data, internal links, images, sitemap and robots rules.
3. Identify safe data connections for Search Console, analytics and approved backlink data.
4. Propose a dashboard data model and interface that clearly distinguishes live data, calculated scores and unavailable sources.
5. Create a prioritized backlog divided into critical fixes, quick wins, content, authority and measurement.
6. Implement only reversible local changes.
7. Stop for approval before deployment, account creation, submissions or outreach.

Do not invent metrics, create spam backlinks, manufacture business locations or promise rankings.
